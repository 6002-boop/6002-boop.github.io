02 — Case Studies

專案實踐

PROJECT 01 · CONSUMER BEHAVIOR
電商會員價值分群與流失預警模型
行為分析 · 440,206 筆消費紀錄處理 · Power BI 數據視覺化
+
商務背景與核心問題
電商平台面臨客群結構鈍化問題：經初步檢視，約 16% 客戶已實質流失、22% 高價值核心客戶處於不活躍狀態。本專案旨在透過定量分析，識別具備高挽回價值的核心群體，並量化其對營收的潛在貢獻。
數據工程與方法論
Power Query RFM 模型 百分位排名 (Percentile) 多源 CSV 清洗與合併
運用 Power Query 清洗並合併 22 份跨區域銷售訂單資料，排除重複與格式異常。基於 Recency、Frequency、Monetary 行為指標建立三維分群，利用百分位算法將會員結構解構為 8 類行為群體，以精準鎖定目標受眾。

數據洞察與營運建議
  • 識別出 5.5 萬名核心高價值客戶，平均未回購天數達 400 天，若無即時干預，潛在營收流失風險高達每年 2 億新台幣。
  • 提出分段式行銷介入規劃：針對 181-270 天沉睡者提供專屬優惠券（經評估此階段轉化 ROI 最高）；271-365天導入特定贈品誘因；366天以上採取自動化電子郵件喚醒。
  • 根據歷史轉化率推估，該策略預計可有效挽回 16,358 名高價值會員，帶來約 NT$6,300 萬的營收回補。
PROJECT 02 · MARKET INTELLIGENCE
AI 算力供應鏈分析：NVIDIA 區域營收轉移與台廠元件商利潤結構研究
官方 10-K 財報定量分析 · FY2016–FY2026 十年軌跡追蹤 · MySQL · Python
+
研究問題與分析範疇
本報告跳脫市場質化新聞的直覺推論，直接提取 NVIDIA 歷年原始 10-K 申報文件進行多年度定量分析，量化出口管制對其核心業務的真實衝擊。同時，沿著供應鏈向下解構台積電先進封裝（CoWoS）、韓廠高頻寬記憶體（HBM）與台灣高階被動元件廠商在此變局中的結構性利潤分配與定價權。
分析工作流（AI 協作與數據驗證）
MySQL 營收聚合 Python (matplotlib) NVIDIA 10-K 數據庫 AI 語法協作開發
建立多年度官方財報資料集。在此專案中，我負責整體的「商業指標定義」與「多因子架構設計」，並透過 Prompt 工程導引生成式 AI 輔助產出 MySQL 提取與 Python 繪圖語法。在數據驗證階段，主動對照原始 10-K 會計報表，修正了初版因申報定義差異（Billing vs HQ Location）導致的 FY2017 誤差，確保資料具備跨年度的一致性。

核心商務洞察
  • 指標解讀的相對性： NVIDIA 中國市場營收佔比雖從 26.4% 降至 9.1%，但絕對金額實質成長 2.8x。主導整體業績的是北美四大 CSP 需求帶動的美國市場（同期暴增34x），完全補足並稀釋了中國市場份額。
  • 供應鏈瓶頸位移： 數據與市場調研顯示，台積電 CoWoS 封裝良率已穩定超越 98%，原封裝端瓶頸基本解鎖；當前實質風險已轉移至韓廠 HBM4 認證延遲。經情境敏感度分析（以 ASP $35,000 美元計），此技術延遲使次世代 Rubin 架構晶片年度預估產量面臨 25% 下修，屬於「營收遞延認列」，而非結構性衰退。
  • 被動元件廠之結構性優勢： 相比系統代工廠維持低毛利加工費、HBM 顆粒利潤集中於外商，台灣以國巨為首的高階被動元件（特殊 MLCC/高階電感）原廠，在 AI 伺服器對高頻、高壓、高可靠性的硬體硬指標要求下，具備較高的技術防禦壁壘。在去中國化浪潮下，中國廠商短期內難以通過高階規格認證，使台廠享有穩固的產品利潤與定價權。

03 — Biography

個人背景與分析核心

我是許毅謙（Yi-Chien Hsu）。大學就讀歷史學系，碩士班主修考古學，在學期間曾深入接觸並操作碳氧、碳氮同位素的科學定量分析。

這段學術背景培養了我對數據的嚴謹態度。考古定量研究的核心，是在高度不完整、無序的樣本與環境變數中，利用精密儀器輸出客觀數據，再透過邏輯交叉比對，推論出當時經濟與社會結構的真實軌跡。這與商業數據分析中，從凌亂的銷售日誌或複雜的跨國財報中提煉商務洞察，在邏輯本質上高度一致。

不論是在電商專案中透過 RFM 行為模型量化 44 萬筆會員的沉睡損失，還是在科技產業研究中藉由原始 10-K 申報文件追蹤 NVIDIA 去中國化的結構性位移與 HBM4 技術卡點，我的核心價值在於：「精確界定商務命題、維護數據一致性、並將其轉化為具備決策參考價值的量化建議。」

在技術實作上，我熟練運用生成式 AI 作為我的高效技術助手（Assistant-Driven Workflow），由我負責核心的「指標設計」與「問題拆解」，並透過精確的 Prompt Engineering 導引 AI 產出 SQL 與 Python 語法。我認為這能大幅降低語法編寫的重複性時間，使我能將 80% 的精力專注於數據背後的商業解讀。目前正積極尋找 B2B 科技原廠、品牌外商或第三方產業調研機構的 Data Analyst 或 Business Analyst 機會。
