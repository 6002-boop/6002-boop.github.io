PROJECT 01 · 2025
喚醒高價值客群與流失預警
會員 RFM 模型分析 · 440,206 筆消費紀錄 · Power BI
+
問題定義
電商會員平台面臨客戶結構失衡：16% 客戶已流失、22% 高價值客戶陷入沉睡。 核心問題是如何在龐大會員基數中，識別值得搶救的高價值客群並設計對應的挽回策略。
方法與工具
Power BI Power Query RFM 模型 百分位排名 22 份 CSV 合併
合併 22 份 CSV 訂單資料，清洗 44 萬筆會員紀錄，建立 RFM 三維評分系統（Recency、Frequency、Monetary）， 依百分位排名將客戶分為 8 種行為群體，識別高價值沉睡客戶。

400
平均沉睡天數
關鍵洞察與行動建議
  • 5.5 萬名高價值客戶平均 400 天未回購，若流失年損 2 億新台幣
  • 設計三階段挽回計畫：181–270 天（折扣券）、271–365 天（25% 折扣 / 贈品）、366 天以上（低成本自動化信）
  • 三階段預估可挽回 16,358 名客戶，年增營收 NT$6,300 萬
  • 建議優先集中資源於 181–270 天群體，ROI 最高
PROJECT 02 · 2026
AI 算力供應鏈分析：輝達去中國化的數據軌跡
NVIDIA 10-K 財報分析 · FY2016–FY2026 · MySQL · Python
+
研究問題
中國禁止購入輝達晶片，會對輝達業務造成嚴重衝擊嗎？ 從 FY2016 到 FY2026 的完整 10-K 財報數據，追蹤這場地緣政治衝擊的真實影響， 並沿著供應鏈向下追蹤台積電、HBM 記憶體、設備商的連動關係。
方法與工具
MySQL Python Google Colab matplotlib NVIDIA 10-K
直接引用 NVIDIA 官方財報建立資料集，以 MySQL 進行多年度地區營收聚合與占比計算， Python 產出三張視覺化圖表，並透過情境試算量化 HBM4 延遲對 Rubin 產線的營收影響。 報告草稿由 Claude 協助架構，最終排版由 Gemini 輔助完成。

FY2016–FY2025 採 Billing Location；FY2026 起改為 HQ Location，不可直接比較。 FY2017 數據經對照原始 10-K 修正（初版錯誤已記錄於 GitHub commit）。

關鍵洞察
  • 中國市占 FY2022 見頂後持續下滑，出口管制加速了一個已在進行中的結構轉移
  • 中國絕對值成長 2.8x，美國成長 34x——同一數字的兩種故事，光看絕對值會誤判趨勢
  • FY27 Q2 財測 $910 億明示排除中國收入，去中國化不影響成長動能
  • 台積電 CoWoS 良率 >98% 已解除封裝瓶頸；HBM4 認證延遲才是 Rubin 出貨的真正卡點
  • 台灣在供應鏈賺加工費而非技術溢價，HBM 本體利潤留在韓廠

03 — About

關於我

歷史系出身，碩士專攻考古學，論文研究涉及碳氧、碳氮同位素分析—— 在那之前，沒想過自己會喜歡跟數字打交道。

從操作質譜儀、解讀同位素數值、到獨立撰寫研究報告， 我發現自己真正在意的，是從雜亂的資料裡找出一個說得通的結論。 這個習慣帶著我從史前遺址走進商業數據： 用 RFM 模型分群 44 萬筆會員記錄，用 Power BI 把數字轉化為可執行的挽回策略； 再到每天閱讀科技財報，用 MySQL 和 Python 追蹤輝達十年供應鏈的結構轉移—— 本質上做的是同一件事：讓數字說出一個說得通的故事。

目前透過持續的自主專案深化分析能力，涵蓋消費者行為分析與產業供應鏈研究兩個方向， 尋找 B2B 科技業的 Data Analyst 或 Business Analyst 入門機會。
